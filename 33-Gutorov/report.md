## Задача 1. Максимум и минимум

Найти минимальный и максимальный элементы массива целых чисел.

### Идея решения

Первое число принимается за начальный минимум и максимум.
Каждое следующее число сравнивается с текущими значениями.
При необходимости минимум или максимум обновляется.

Числа обрабатываются последовательно, без хранения всего массива.

### Асимптотика

Для n чисел выполняется n − 1 повторений цикла.
Каждое повторение содержит постоянное количество операций.

Время: O(n).
Дополнительная память алгоритма: O(1).

### Проверки

- `7 -2 10 0 4` → `-2 10`: числа разных знаков и ноль.
- `5 9 3` → `3 9`: только положительные числа.
- `-5 -9 -2` → `-9 -2`: только отрицательные числа.
- `4 4 4` → `4 4`: одинаковые элементы.
- `-2147483648 2147483647` → тот же результат:
  минимальный допустимый размер массива и крайние значения int.

## Задача 2. Индекс первого вхождения

Найти индекс первого элемента массива, равного заданному числу.
Если такого элемента нет, вывести -1.

### Формат ввода

Количество элементов n, затем n целых чисел, затем искомое число x.
Индексация начинается с нуля.

### Идея решения

Массив просматривается слева направо.
При первом совпадении сохраняется индекс и поиск завершается.
Если совпадений нет, выводится -1.

Массив хранится в памяти, поскольку число x вводится после элементов.

### Асимптотика

Чтение массива занимает O(n).
Поиск выполняет не более n сравнений и занимает O(n).
Общее время программы: O(n).
Память: O(n) для хранения массива.

### Проверки

- `7 3 10 3 4`, x = 3 → 1: первое из нескольких совпадений.
- `2 4 6`, x = 5 → -1: число отсутствует.
- `8 2 5`, x = 8 → 0: совпадение в начале.
- `8 2 5`, x = 5 → 2: совпадение в конце.
- `-7 -3`, x = -3 → 1: отрицательные числа и минимальный размер.

## Задача 25. Сумма элементов

Найти сумму всех элементов массива целых чисел.

### Идея решения

Начальная сумма равна нулю.
Каждое прочитанное число прибавляется к сумме.
Хранить весь массив не требуется.

Для суммы используется long: результат может превышать диапазон int.
При заданных ограничениях на размер массива сумма помещается в long.

### Асимптотика

Цикл выполняется n раз, каждое повторение занимает O(1).

Время: O(n).
Дополнительная память алгоритма: O(1).

### Проверки

- `7 -2 10 0 4` → 19: числа разных знаков и ноль.
- `-5 -9 -2` → -16: отрицательные числа.
- `0 0 0` → 0: все элементы равны нулю.
- `7 -7 3 -3` → 0: взаимное сокращение чисел.
- `2147483647 2147483647` → 4294967294:
  сумма превышает диапазон int.

## Задача 27. Сумма квадратов

Найти сумму квадратов всех элементов массива целых чисел.

### Идея решения

Числа читаются последовательно.
Квадрат каждого числа прибавляется к общей сумме.
Хранить массив не требуется.

Перед умножением число записывается в long:
квадрат любого значения int помещается в long.
Сумма хранится в BigInteger, поскольку может превышать диапазон long.

### Асимптотика

При заданных ограничениях n < 100000 и значениях типа int
размер суммы ограничен, поэтому операции над ней имеют
ограниченную стоимость.

Время: O(n).
Дополнительная память: O(1) при заданных ограничениях.

Если рассматривать неограниченный рост n, сумма занимает
O(log n) бит, а последовательное сложение — O(n log n) времени.

### Проверки

- `2 -3 4` → 29: числа разных знаков.
- `-5 -9 -2` → 110: отрицательные числа.
- `0 0 0` → 0: нулевые элементы.
- `50000 -50000` → 5000000000:
  квадраты и сумма превышают диапазон int.
- Три числа `-2147483648` → 13835058055282163712:
  сумма превышает диапазон long.

  ### Покрытие тестами

Покрытие измерено JaCoCo 0.8.15:
- инструкции — 91%;
- ветвления — 100%;
- строки — 9 из 10, 90%.

## Задача 31. Скалярное произведение

Найти сумму произведений элементов двух массивов
с одинаковыми индексами.

### Формат ввода

Общий размер n, затем n элементов первого массива,
затем n элементов второго массива.

### Идея решения

Первый массив сохраняется в памяти.
Элементы второго массива читаются последовательно.
Каждый элемент умножается на соответствующий элемент первого массива.
Произведения прибавляются к общей сумме.

Произведение вычисляется в long, сумма хранится в BigInteger,
чтобы избежать переполнения.

### Асимптотика

При заданных ограничениях размера массивов и значениях типа int
стоимость операций над суммой ограничена.

Время: O(n).
Память: O(n) для первого массива.

При неограниченном росте n последовательное накопление
суммы в BigInteger занимает O(n log n) времени.
Память остаётся O(n).

### Проверки

- `[1, 2, 3]` и `[4, 5, 6]` → 32: обычный случай.
- `[-1, 2, -3]` и `[4, -5, -6]` → 4: разные знаки.
- `[0, 0, 0]` и `[4, -5, 6]` → 0: нулевой массив.
- `[50000, 50000]` и `[50000, 50000]` → 5000000000:
  результат превышает диапазон int.
- Два массива из трёх значений -2147483648 →
  13835058055282163712: результат превышает диапазон long.
