## Задача 1. Максимум и минимум

Найти минимальный и максимальный элементы массива целых чисел.

### Идея решения

Первое число принимается за начальный минимум и максимум.
Каждое следующее число сравнивается с текущими значениями.
При необходимости минимум или максимум обновляется.

Числа обрабатываются последовательно, без хранения всего массива.

### Асимптотика

Для n чисел выполняется n − 1 повторений цикла.
Каждое повторение содержит постоянное количество операций.

Время: O(n).
Дополнительная память алгоритма: O(1).

### Проверки

- `7 -2 10 0 4` → `-2 10`: числа разных знаков и ноль.
- `5 9 3` → `3 9`: только положительные числа.
- `-5 -9 -2` → `-9 -2`: только отрицательные числа.
- `4 4 4` → `4 4`: одинаковые элементы.
- `-2147483648 2147483647` → тот же результат:
  минимальный допустимый размер массива и крайние значения int.

## Задача 2. Индекс первого вхождения

Найти индекс первого элемента массива, равного заданному числу.
Если такого элемента нет, вывести -1.

### Формат ввода

Количество элементов n, затем n целых чисел, затем искомое число x.
Индексация начинается с нуля.

### Идея решения

Массив просматривается слева направо.
При первом совпадении сохраняется индекс и поиск завершается.
Если совпадений нет, выводится -1.

Массив хранится в памяти, поскольку число x вводится после элементов.

### Асимптотика

Чтение массива занимает O(n).
Поиск выполняет не более n сравнений и занимает O(n).
Общее время программы: O(n).
Память: O(n) для хранения массива.

### Проверки

- `7 3 10 3 4`, x = 3 → 1: первое из нескольких совпадений.
- `2 4 6`, x = 5 → -1: число отсутствует.
- `8 2 5`, x = 8 → 0: совпадение в начале.
- `8 2 5`, x = 5 → 2: совпадение в конце.
- `-7 -3`, x = -3 → 1: отрицательные числа и минимальный размер.

## Задача 25. Сумма элементов

Найти сумму всех элементов массива целых чисел.

### Идея решения

Начальная сумма равна нулю.
Каждое прочитанное число прибавляется к сумме.
Хранить весь массив не требуется.

Для суммы используется long: результат может превышать диапазон int.
При заданных ограничениях на размер массива сумма помещается в long.

### Асимптотика

Цикл выполняется n раз, каждое повторение занимает O(1).

Время: O(n).
Дополнительная память алгоритма: O(1).

### Проверки

- `7 -2 10 0 4` → 19: числа разных знаков и ноль.
- `-5 -9 -2` → -16: отрицательные числа.
- `0 0 0` → 0: все элементы равны нулю.
- `7 -7 3 -3` → 0: взаимное сокращение чисел.
- `2147483647 2147483647` → 4294967294:
  сумма превышает диапазон int.
